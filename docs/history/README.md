# Historical planning archive

These documents are preserved as an engineering record. They predate and are
superseded by the implemented 1.0 product direction in
[`docs/product/`](../product/). Do not use them as current requirements or contributor
guidance.

- [`Spec.md`](Spec.md) is the original broad product specification.
- [`handoffs/`](handoffs/) contains session prompts written before the local-workbench
  direction was frozen. Some describe work that was later changed, replaced, or
  deliberately excluded from 1.0.
